## 真机验收记录

候选版构建产物中的 `device-check.md` 已带上版本、提交、APK 摘要和签名比对结果。测试时填写设备型号、系统或兼容环境版本、日期；每行记录「通过／失败／未测」和观察结果。将填写后的记录附到该候选版的验收记录或关联 PR；失败时写下重现步骤。

| 场景 | 操作与预期 | 真机结果 |
| --- | --- | --- |
| 覆盖安装 | 从上一正式版直接覆盖；打开后仍是原成员，日程与推送绑定可见。 | 未测 |
| 弱网与重连 | 已加载首页后断网，保留旧快照和时间提示；恢复联网后自动补回最新数据。 | 未测 |
| 七天日程 | 填两段，尝试快捷替换并取消；切换页面再回来，保存后从另一台设备核对。 | 未测 |
| 车票与预约 | 发车、延时回复、创建及改期；所选开始时间过期时须重新选择。 | 未测 |
